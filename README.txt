RESTAURANT DRINKS BOOK — QUICK START

OPEN ON YOUR PC
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html. It opens in your browser.

REPLACE PHOTOS
1. Put your restaurant photos in the images folder.
2. Open drinks.js in Notepad or (recommended) Visual Studio Code.
3. Find the drink you want and change its image value, for example:
   "image": "images/passion-fruit-martini.jpg"
4. Save drinks.js. Keep the photo file in the images folder.
Use landscape photos around 1200 x 800 pixels where possible.

EDIT RECIPES
Open drinks.js. Each drink has a name, category, image, steps and note.
Edit the steps array to change the numbered instructions.
For future classic cocktails, add drink entries with category: "classics".
The Classic Cocktails tab is intentionally empty in this starter version.

SHARE ONLINE (NETLIFY)
1. Create an account at https://www.netlify.com/
2. In Netlify, choose Add new site / Deploy manually (labels can vary).
3. Drag the extracted restaurant-drinks-app folder into the deploy area.
4. Netlify gives you a public website URL. Share that URL with staff.
5. After edits, upload the updated folder again to publish the changes.

This is a static website: no database or installation is required. Anyone with the link can view it. Keep a backup of the folder on your PC.

IMPORTANT
The recipes are transcribed from the information supplied in the conversation and may need checking. Confirm every measure and preparation step against the restaurant's approved spec before using for service.
